# Focus ring

When someone moves through a page with the keyboard, the focus ring shows where they are. Every focusable Themis
control draws the same one: **2px dashes, alternating black and white, just outside the control.**

<RingOnBackgrounds />

One of the two dash colors always has at least 3:1 contrast with the background, so the ring shows whatever colors a
theme uses, including ones nobody planned for.

## Try it

Click in the box below, then press **Tab** and **Shift+Tab**. The ring follows the keyboard. Click a control with the
mouse and it doesn't appear: a pointer already shows where you are.

<TryIt />

## How it's drawn

<table>
  <thead>
    <tr><th>Part</th><th>What it is</th><th>Why</th></tr>
  </thead>
  <tbody>
    <tr><td>Dashed outline</td><td>A 2px black <code>{"outline"}</code>, 2px out from the control</td><td>Outlines don't take up space, so focusing a control never moves anything</td></tr>
    <tr><td>White backing ring</td><td>A solid 2px white ring under the outline (the control's <code>{"::before"}</code>)</td><td>Fills the gaps between the dashes, giving the second color</td></tr>
    <tr><td>Gap</td><td>2px (<code>{"spacing.3xs"}</code>) between the control and the ring</td><td>Keeps the ring readable against the control's own border</td></tr>
    <tr><td>Corners</td><td>The control's radius plus the gap</td><td>The ring follows the shape of what it surrounds</td></tr>
  </tbody>
</table>

The width comes from the `border.width.focus ring` token, which is 2px in every border-width mode, so even a
borderless theme keeps a full ring.

**Windows high-contrast mode** replaces custom colors with the user's system colors. There the white ring is dropped
and the outline takes the system color.

## Using it in a component

Use `focusRing` from `src/utils/focus-ring.ts`, and apply `visible` only for keyboard focus (React Aria's
`isFocusVisible`), with `racStyles()`:

```tsx
{...racStyles<ButtonRenderProps>(({ isFocusVisible }) => [
  styles.base,
  focusRing.base,
  isFocusVisible && focusRing.visible,
])}
```

- The element needs `position: relative` (the white ring is positioned against it) and the `radius.md` corners. For
  `radius.sm` corners add `focusRing.radiusSm` too.
- The ring uses the element's `::before`, so don't use `::before` for anything else on it.
- Where an outside ring would spill out of its container or overlap neighbors, draw it just inside the element with
  `focusRing.inset` instead: Accordion headers, and text fields (which show it while anything inside them has focus).

AA is the WCAG level Themis supports.
