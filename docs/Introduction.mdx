# Themis

Themis is a parametric, accessible React design system.

- **Behaviour & accessibility** come from [React Aria Components](https://react-spectrum.adobe.com/react-aria/).
- **Styles** are written in [StyleX](https://stylexjs.com) and compile to atomic CSS.
- **Design tokens** are exported from Figma variables in [DTCG](https://www.designtokens.org/) format and compiled into StyleX variables.

## Using Themis

```tsx
import 'themis-ds/styles.css';
import { Button, ThemeProvider } from 'themis-ds';

export function App() {
  return (
    <ThemeProvider modes={{ colorTheme: 'light demo', fontTheme: 'demo' }}>
      <Button variant="primary" onPress={save}>Save changes</Button>
    </ThemeProvider>
  );
}
```

**Fonts:** Themis sets font families through tokens but doesn't load font files. Your app must load the fonts it uses
(for the demo themes: Montserrat, Playfair Display, Outfit, Fredoka One and Space Mono). Storybook loads them from
Google Fonts in `.storybook/preview-head.html`.

Each multi-mode token collection has its own toolbar control (**colorTheme**, **fontTheme**, **radius** and **borderWidth**). Use them to preview every story in each mode.

## Source of truth

Storybook is the source of truth; Figma consumes it.

| Consumer | Where it reads from |
| --- | --- |
| People | The **Docs** page of each component |
| AI agents | Storybook MCP at `/mcp`, plus [`/themis-manifest.json`](./themis-manifest.json) |
| Figma | [`/themis-manifest.json`](./themis-manifest.json): props, Figma property mapping, tokens and guidance |

Every component's Docs page follows the same structure: Usage, Variants, Anatomy, Guidelines,
Accessibility, Design tokens, Figma mapping, Examples, API reference.
